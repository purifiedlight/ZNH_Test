# Test Project of 3D City Models

This project is a test showcase of 3D models of various cities, developed in collaboration with the Technical University.

## Project Description

The project contains 3D models of cities created for research, visualization, and testing purposes. It currently serves as a prototype and foundation for further development and expansion.

## Collaboration

This project was developed in cooperation with the Technical University, where we jointly worked on modeling and visualizing urban spaces.

## Usage

The project is primarily intended for testing and validating concepts in the field of 3D city modeling.
